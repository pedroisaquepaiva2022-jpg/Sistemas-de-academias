# Sistema de Academia Pro

Protótipo pessoal de um sistema web voltado ao uso por personal trainers, desenvolvido para organizar treinos e informações relacionadas aos alunos.

## Visão geral

O projeto explora a construção de uma interface web para apoiar a organização de divisões e fichas de treinamento. A proposta é reunir, em um só ambiente, recursos básicos de gerenciamento e visualização de informações.

Este repositório apresenta o projeto como um protótipo em desenvolvimento, não como um produto comercial ou uma plataforma pronta para produção.

## Funcionalidades e recursos planejados/explorados

- Organização de divisões e fichas de treinamento;
- Armazenamento local de informações no navegador com `localStorage`;
- Visualização de dados por meio de gráficos com Chart.js;
- Geração de documentos PDF com jsPDF;
- Interface com tema escuro e elementos visuais em verde.

> A disponibilidade e o funcionamento de cada recurso dependem dos arquivos e da versão do código publicados neste repositório.

## Tecnologias

- HTML, CSS e JavaScript;
- Web Storage (`localStorage`);
- Chart.js;
- jsPDF.

Ferramentas de inteligência artificial foram utilizadas como apoio ao processo de aprendizagem, pesquisa, revisão e desenvolvimento assistido. A IA é uma ferramenta de apoio; as funcionalidades devem ser avaliadas pelo código efetivamente publicado.

## Como executar

Quando os arquivos-fonte estiverem publicados:

1. Baixe ou clone o repositório.
2. Abra o arquivo principal `index.html` em um navegador moderno.
3. Caso o projeto utilize bibliotecas carregadas por CDN, mantenha a conexão com a internet durante a execução.

## Armazenamento e limitações

O uso de `localStorage` mantém os dados no navegador e no dispositivo em que foram cadastrados. Isso não equivale a um banco de dados remoto, sincronização entre dispositivos, autenticação de usuários ou backup centralizado.

Este protótipo não deve ser utilizado para armazenar informações sensíveis ou dados reais de alunos sem uma avaliação adequada de segurança, privacidade, controle de acesso e proteção de dados.

## Objetivo de aprendizagem

Praticar conceitos de desenvolvimento web, estruturação de interfaces, organização de funcionalidades, armazenamento local, visualização de dados e geração de documentos, com apoio de ferramentas digitais e de inteligência artificial.
